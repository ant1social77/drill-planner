# Drill Planner

**Drill & Training Planner** — HTML-планировщик судовых учений и тренировок.

## Как открыть
**Онлайн:** https://ant1social77.github.io/drill-planner/

**Без интернета:** скачать [Drill_Planner.html](Drill_Planner.html) и открыть двойным щелчком — запустится в браузере.

## Перенос данных между устройствами
Данные хранятся в браузере конкретного устройства. Чтобы перенести: **⬇ Export** на старом устройстве → перенести файл `.json` → **⬆ Import** на новом.
