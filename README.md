# Drill Planner

**Drill & Training Planner** — HTML-планировщик судовых учений и тренировок.

## Как открыть
Скачать [Drill_Planner.html](Drill_Planner.html) и открыть двойным щелчком — запустится в браузере, интернет не нужен.
